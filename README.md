快速开始（macOS，需先安装造世界编辑器并用同一个抖音账号登录）：

```bash
git clone https://github.com/eiddiedev/DRAGON.git ~/Documents/awesomeWRLD
~/Documents/awesomeWRLD/tools/fix_paths.sh        # 用户名或路径不同时
~/Documents/awesomeWRLD/tools/restore_project.sh  # 编辑器停在首页时运行
```
