## 一、基调：自由游玩，夜里的挑战自愿参加

这个世界首先是一个可以逛的地方：看风景、骑马、喝女巫的怪药水、在篝火边烤蘑菇。它不是一局有输赢的游戏，没有失败条件，也不逼玩家去打怪。

夜里的怪物是**自愿参加的挑战**。设定上这样圆：

- **灯火所及之处，影灵不敢靠近。** 村子、主路、城堡都点着灯，夜里路灯亮起，这个功能已经做好了。待在灯下就是安全的，只想看夜景的人可以沿着亮着的路随便走。
- **灯火之外是守夜人的夜。** 影灵在暗处游荡，玩家愿意的话就离开灯光去打它们。打散的影灵会化成**月辉**，月辉能换东西，也能拿去孵龙蛋。
- **白天没有影灵。** 时之晷是封印的钟，白天封印牢固，影灵出不来。

**塔防降级为附属玩法：守夜灯。** 玩家可以在暗处插一盏守夜灯。灯能把附近的影灵逼退，也会自动灼烧它们，相当于玩家自己扩大一块安全区，或者打怪时用来歇脚。每人最多插 3 盏，天亮自动熄灭。主玩法仍然是第三人称战斗。

## 二、世界观

### 一句话

古龙墨曜用自己的梦封住了天上的裂隙，从此长眠。玩家是新来的守夜人，夜里提灯走进黑暗，收集龙梦的碎片，想让墨曜留下的龙蛋醒来。

### 开场古书正文

开场时一本古书翻开，共五页，每页一段。标题用朱砂红，正文用墨色。

> **第一页 · 蚀月**
>
> 很久以前，天空裂开了一道口子。
> 人们叫它蚀月之隙。
> 每到夜里，从裂隙里落下的不是星光，而是影子——
> 没有形状，没有声音，只会循着温度游荡的影灵。

> **第二页 · 墨曜**
>
> 古龙墨曜从北方的山脊飞来。
> 它没有去撕咬那些影子，
> 而是在最高的山峰上盘起身子，闭上了眼睛。
> 它用自己的梦，把裂隙缝上了。
> 从此，这片土地有了名字：龙眠之境。

> **第三页 · 守夜人**
>
> 龙的梦并不完美。夜深时，总有影灵从梦的缝隙里漏出来。
> 于是人们点起了灯。
> 灯火所及之处，影灵不敢靠近；灯火之外，是守夜人的夜。
> 守夜人提灯走进黑暗，把影灵打散成月辉——
> 那是龙梦的碎片。

> **第四页 · 龙蛋**
>
> 墨曜入睡前，在城堡深处留下了一枚蛋。
> 守夜人相信，只要月辉、篝火与星露一同落在蛋壳上，
> 龙就会认出它的守护者。
> 一代代守夜人老去，蛋始终没有醒。

> **第五页 · 你**
>
> 如今城堡空了，灯还亮着。
> 你在晷石原醒来，手里握着一张旧地图。
> 白天，这片土地属于你：去走，去看，去骑马，去喝女巫那些古怪的药水。
> 夜里，如果你愿意——就提灯出去。
>
> 墨曜在等。（这一句用朱砂红）

最后一页翻过去时，那张旧地图从书里飞出，缩成左上角的地图按钮。

### 龙、龙蛋和骑龙怎么圆

这一段要和已经实现的骑龙逻辑对上：龙停在山顶，在祭坛召唤，飞完回到山顶。

- 山顶那条龙就是**墨曜本身**。它一直在睡，偶尔动一下。
- **龙蛋**放在城堡的龙巢圣所里。月辉、火种、星露三样凑齐后，蛋壳裂开，飞出一团**龙魂火**，钻进玩家胸口，结成**龙契**。
- 有了龙契，在**唤龙祭坛**就能唤来墨曜的**梦身**：它的身体还在睡，梦里的它飞下来载你。飞完了它回到山顶，继续睡。
- 这样龙可以骑，名字里的「眠」也成立。之后要做最终事件的话，可以是很多守夜人同一晚骑龙飞进蚀月之隙，墨曜醒来一次。

**孵蛋三样东西：**

| 东西 | 来源 | 对应玩法 |
|---|---|---|
| 月辉 | 夜里打散影灵 | 战斗挑战（主玩法） |
| 火种 | 篝火「烤蘑菇」小游戏烤出完美的一串 | 篝火 |
| 星露 | 白天采材料，交给女巫调制 | 女巫、采集 |

还没有龙契时，靠近祭坛只显示提示：「墨曜还不认得你。」

### 守夜人誓约（可选的职业）

在城堡王座厅立誓时选一种誓约，之后可以回来更换。三种职业只换武器和技能特效，不换人物模型，省容量。

- **剑誓 · 骑士**：近战，有护盾，守夜灯插得更快。
- **星誓 · 巫师**：远程法球，药水效果更持久。
- **风誓 · 游侠**：弓箭，骑马更快，能看到附近影灵的位置。

### 影灵

- 外形是一团黑烟，带一对发光的眼睛，被打散时化成月白色的光点。**不要出现血或肢体。**
- 三种影灵用同一个模型，改颜色和大小：
  - **游影**：小，跑得快。
  - **沉影**：大，耐打。
  - **月影**：发光，掉的月辉多。
- 夜里从**裂隙之门**（城堡脚下的传送门）里涌出，向四周的暗处散开。

- **《守夜人手札》**：讲影灵的习性，教玩家灯下安全、暗处才有影灵。
- **《女巫的配方（残页）》**：讲星露的配方，以及几种怪药水的说明。说明不可靠，这本身就是笑点。

## 三、开场流程

1. **加载页**：如果平台的加载页不能改，就在进入世界后先黑屏，叠上胶片颗粒，再淡入一行小字「龙正在沉睡……」。
2. **标题页**（见下一章）：背景是实时运行的世界，镜头停在一个机位上慢慢推移，画面中间是「龙眠之境」标题，点击屏幕任意处开始。
3. **点击后**：标题像墨迹一样散开淡出（0.6 秒），镜头用 2 到 2.5 秒平滑飞到角色背后，颗粒感跟着淡掉，界面元素淡入。
4. **第一次进入**：翻开古书，五页序章。点击或滑动翻页，右上角有「跳过」。翻完后地图飞到左上角，变成地图按钮。
5. **再次进入**：跳过古书，直接从第 3 步进入游戏。之后可以在寝殿或王座厅重读序章。

## 四、UI 定调

整套 UI 只用两种视觉语言，不要混出第三种。

### 1. 夜与梦：只用在标题页和少数大字

参考用户给的第一张图：黑夜实景，画面颗粒感重，色调偏旧，中间是手绘感很强的红字，黑色描边，下面是一行很小的白字。

- **标题「龙眠之境」**：
  - 朱红色 `#E2381E`，带一圈不均匀的黑色粗描边 `#0E0B0A`。
  - 笔画像马克笔或刷子手写，粗细不均，略歪，边缘有抖动。不要做成书法体，也不要像游戏 Logo。
  - 用图片资源实现，不用字体。可以做 3 帧有细微差别的版本，以每秒 8 帧循环，像手绘动画那样微微抖动（boil）。这是最有意境的一点。
- **副标题**：「轻触任意处 · 入梦」，小号白色无衬线字，约为标题高度的 1/12，透明度在 0.5 到 1 之间缓慢呼吸。
- **画面处理**：
  - 全屏叠胶片颗粒（每帧换噪点），加重暗角，略微降低饱和度。
  - 不要用 UI 面板压在画面上，只放字。
- **标题页机位**：从镜湖或月桥南侧看向龙眠堡，月亮、漩涡和城堡同框。镜头每 20 秒左右在两三个点之间缓慢推移。
- 第一张参考图的字体和文字都不能用（版权），只参考气质，标题字要原创。

### 2. 古卷：地图、书、对话、提示都用这一套

参考用户给的第二张图（羊皮纸地图）和第三张图（古书）。

**颜色：**

| 用途 | 色值 |
|---|---|
| 纸 | `#EADCBF` |
| 纸边（焦旧） | `#B89668` |
| 墨（正文、线条） | `#2E2116` |
| 淡墨（次要文字） | `#6B5640` |
| 朱砂（标题、印章、玩家标记、重要提示） | `#9C2B1E` |
| 铜（书角、边框金属件） | `#8A6A3A` |
| 皮革（书封、按钮底） | `#2A2420` |

**字体：**
- 正文用**思源宋体**（Source Han Serif）或**霞鹜文楷**（LXGW WenKai），两者都是 SIL OFL 开源授权，可以商用。
- 不要用方正、汉仪等商业字体，否则过不了审核。
- 平台如果不能加载自定义字体，固定文字（标题、页眉、地名）就烘焙成图片，动态文字用平台默认字体，并把颜色改成墨色。

**纸张：**
- 底色带不均匀的旧化，四边焦黄，有细小的纤维和颗粒。
- 书页边缘略有破损，像第三张图那样。
- 不要做成干净的米黄色平面。

**动效：**
- 打开时像纸张展开：缩放从 0.96 到 1，同时淡入，约 0.3 秒。
- 翻页用简单的卷页效果，或横向滑动加阴影。
- 关闭时卷起。

**音效**（如果平台的官方音效库里有）：翻纸声、展开卷轴声、盖章声。

### 3. 地图

**收起时**：左上角一个小图标，是一卷羊皮纸，上面压着朱砂蜡封，约 56px。夜里图标边缘有淡淡的暖光。

**展开时**：
- 一整张羊皮纸占屏幕约 85%，背景压暗。风格参照第二张参考图：
  - 墨线勾出海岸线，外面画几圈波纹。
  - 山用「人」字形加排线。
  - 树林用小圆冠符号。
  - 地标用小插画，比如城堡、灯塔、风车、帐篷、蘑菇、祭坛、帆船。
  - 左下角画罗盘，底部写大字标题「龍眠之境」，字距拉开。
- 底图直接用 `map_base_clean.png`，或者以它为底让 Codex 重绘得更精美，海岸线和地点位置不要动。

**坐标换算**（底图 1520×1520，留白 M=120，每米 S=5 像素，北在上）：

```
u = 120 + x * 5
v = 120 + (256 - z) * 5
```

**玩家标记**：一个朱砂红箭头，指向角色朝向，外面一圈呼吸光晕，在羊皮纸上要醒目。

**探索点亮**：没去过的地标只显示淡铅笔线和「？」，走到附近 15 米以内就用墨重新画出来，并弹一个小盖章动效加地名提示，比如「发现 · 萤光古树」。这样自由探索也有动力。

**夜里的地图**：
- 纸面略微变暗，像在灯下看。
- 裂隙之门周围画一圈淡淡的朱砂晕染，表示影灵从这里出来。
- 不实时显示影灵的位置。游侠例外，只显示附近的。

**交互**：点击地标弹出一张小纸条，写地名志里的那一句话。双指缩放可选，不是必须。

### 4. 游戏中的界面

- 界面元素越少越好。常驻的只有左上角的地图按钮、平台自带的摇杆和跳跃键，加一个小的月辉计数（朱砂色小图标加数字，靠在地图按钮下面）。
- 提示条是一张小纸条，从上方滑下来，2.5 秒后卷走。
- 对话框（女巫、王座厅）用古卷样式：纸面加名字印章。

## 五、给 Codex 生图的提示词

1. **标题手绘字**
   > 「龙眠之境」四个中文字，朱红色马克笔手写字，笔画粗细不均、略歪斜、边缘抖动，带一圈不规则黑色粗描边，像涂鸦海报上的手绘标题，透明背景，PNG，2048 宽，原创字形，不像书法、不像游戏 Logo。出 3 张笔画细微不同的版本，用来做手绘抖动动画。
2. **羊皮纸纹理**
   > 无缝可平铺的古旧羊皮纸纹理，米黄色 #EADCBF，带细小纤维、颗粒与不均匀旧化斑，不要文字和图案，1024×1024。另出一张四边焦黄、边缘轻微破损的整页版本。
3. **古书**
   > 俯视角摊开的古书，两页空白羊皮纸，书页边缘泛黄破损，深色皮革封面，四角是铜质护角，书脊和边缘有原创藤蔓压花，透明背景，正面略俯视，高细节写实风格。不要十字形装饰，也不要任何文字。
4. **地图按钮**
   > 卷起的羊皮纸卷轴图标，系着细绳，压着朱砂红蜡封（蜡封上是原创的龙爪纹），手绘插画风，透明背景，256×256。
5. **地图地标小插画**（一套，同一风格）
   > 墨线手绘的中世纪地图符号，深褐墨色单色，线条细腻带排线阴影，透明背景，每个 128×128：哥特城堡、灯塔、风车、帐篷配篝火、发光蘑菇、石祭坛、帆船、石桥、尖顶小屋群、大树、山峰上盘着一条龙的剪影、古老的圆形传送门。风格统一，像羊皮纸地图上的插画，不用十字形。
6. **玩家标记与盖章**

## 六、待验证的技术点

开工前请先确认这些：

1. 平台的 Lua 能不能自己画界面：图片、文字、按钮、全屏点击。素材导入类型里有「UI」，要试它能做到什么程度。
2. 标题页能不能在角色出生前接管镜头，以及能不能先隐藏摇杆等平台自带按钮。镜头接口有 `DouyinCameraService`，要看能否设置机位。
3. 能不能保存玩家数据，比如是否看过序章、去过哪些地点、月辉数量、是否结了龙契。不能保存的话，每次进入都从头开始，序章改成可以跳过就行。
4. 能不能加载自定义字体。
5. 全屏颗粒和暗角对手机帧率的影响，必须用「手机预览」实测。

## 七、审核红线

- 不出现十字形，包括装饰、墓碑和图标。
- 不使用第三方 IP。参考图的字体、文字和图案都只取气质，所有素材都要原创。
- 不出现血。影灵打散时化成光点。
