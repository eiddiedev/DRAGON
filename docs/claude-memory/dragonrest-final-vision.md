用户在 2026-11-05 确认的最终效果：

- 默认进入是黑夜（怪诞：月亮、云雾漩涡天空），白天是圣洁的剑与魔法、龙的世界。夜里的游荡怪物由用户以后自己补，只留位置。
- 时间系统：昼夜自动慢慢循环，同时能到世界里的钟楼前手动切换。
- 城堡：孤立小山上的哥特式城堡，塔尖高而尖；盘山路从桥头蜿蜒上山；白石墙、深蓝尖顶、金饰。不要平台和高架坡道。
- 出生点：抬头看城堡，一棵原创的发光大树框住画面（金白色），树下紫粉花海。形状和名字都不照搬《艾尔登法环》黄金树。
- 环境：草地压暗有层次，雪山要有细节，房子加细节，灯串、路灯、烟花。贴图不把黑夜画死，明暗靠光照，白天黑夜共用。
- 画风保留和编辑器一致的卡通风，比例和细节向参考图靠。

**Why:** 用户要在造世界编辑器比赛里压过上届冠军「海贼岛」，第一眼要惊艳。
**How to apply:** 巨龙和坐骑龙已授权 Claude 用星光让编辑器 AI 生成，事后报告花费；不要上传或发布世界。用户说过「你一直跑，不要停」。实现细节见 [[world-editor-pipeline]]。
