世界观

龙约

千年前，古龙艾瑟拉和这片土地上的人们立下「龙约」：它用龙焰守护王国，人们在雪山脚下修建星塔学院，替它看守沉睡之所。约定立下后，古龙飞上北方最高的雪峰，盘起身子睡着了，一睡就是一千年。

王国在龙的庇护下长成了今天的样子。山谷里，红瓦小镇沿着雪水河一路修到海湾；港口每天都有帆船进出；学院的塔楼一层层挂在悬崖上，从山谷里抬头就能看见。学徒们在浮空图书馆里翻魔法书，女巫薇拉用龙鳞和月光草熬制效果古怪的药水。

但龙会做梦。每当月之钟敲响、蓝月升起，古龙的噩梦就化成「梦魇影」，从雪峰顺着河谷飘下来，钻进森林和街巷。学院的规矩是：每个学徒都要学会用光之魔法和剑驱散它们，守到天亮。

你是今年刚到星塔学院报到的学徒。

一条龙串起一切

城堡是为龙建的，药水用龙鳞熬，夜晚是龙的梦，骑龙是游览方式。评委听一句话就能理解整个世界。

垂直分层

地下竞技场、山谷小镇、悬崖城堡、雪峰龙巢、天空航线，五层高度。走、飞、骑三种方式在层之间移动。

昼夜反差

同一个机位，白天是晨金色的童话，夜晚是蓝月下亮着窗灯的史诗。一张图拿出两套宣传画面。

玩家前五分钟

评委会看到什么

按评委实际的游玩顺序安排。前 90 秒之内，评委不需要自己找路，就能看完全图。

  1. 0:00
    开场运镜

    镜头先拉远对准龙巢和城堡，停 3 秒，再推回出生崖上的玩家背后。用 SetDistance / SetPitch / SetYaw 实现。

  2. 0:05
    站在出生观景崖

    脚下是羊群和草坡，正前方是山谷、小镇、悬崖城堡和雪峰上的龙，右手边是海湾。旁边就是拍照画框和骑龙驿站。

  3. 0:20
    骑龙巡游 90 秒

    沿 11 个航点飞完一圈：小镇 → 港口 → 灯塔 → 海岸 → 城堡塔楼之间 → 绕龙巢 → 幽影林 → 回到驿站。

  4. 2:00
    下山进城

    穿过小镇、过桥上悬崖：药水铺喝一瓶变成羊，图书馆领魔杖，天文塔拿扫帚飞一圈。

  5. 4:00
    敲响月之钟

    全服入夜，蓝月升起，梦魇影从雪峰飘下来。拿魔杖和剑驱散它们，或者下地下竞技场找人对战。

制作顺序

先做出第一眼，再填玩法

任何时候停下来，作品都应该是能看的。所以第一眼画面最先做完，玩法按优先级往上加。

  1. 实测与地形

    跑完下方实测清单；用 128×128 生成地形，笔刷修出雪山、悬崖台地、河谷、海湾。

  2. 第一眼画面

    城堡 + 古龙进场，出生点定朝向，调白天环境。截图对比参考图，满意再往下走。

  3. 骑龙巡游

    驿站 + 航线 + 开场运镜。做完这步就有了一个能交的作品。

  4. 填充场景

    小镇 18 栋、港口灯塔、牧羊坡、幽影林、植被。边摆边看容量。

  5. P1 玩法

    药水铺、魔杖、扫帚、竞技场。

  6. P2 与夜晚

    月之钟、梦魇影、龙蛋孵化；调夜晚环境。

  7. 打磨上传

    手机预览跑通关键路径，白天 / 夜晚同机位各截一张做封面，提交审核（审核要 1–3 个工作日）。

开工前的实测清单

  • 昼夜切换：SceneEnvironment.Change 能否在运行中切换，切换能否同步给房间里所有人。
  • 变身药水：actor.scale 和 SetVisible 能否作用在官方小火人上；去官方群确认这算不算「官方形象二改」。
  • 地图尺度：128×128 时 1 格对应多少米，小火人走一格要多久（决定航线长度和建筑尺寸）。
  • 远景：大模型能不能摆到地形边界外面当远山；巨龙放大到 45h 后容量占多少。
  • 骑乘：热气球组件改成龙之后，航点能拉多远、飞多高，能不能坐 2 人。

审核红线自查

  • 世界名、简介、标签、封面里不出现权游、哈利波特、塞尔达等任何第三方 IP 名称。
  • 不做分院帽、魁地奇、三角力量、铁王座等标志性元素；城堡轮廓避开霍格沃茨的经典剪影。
  • 剑和魔杖做成发光的奇幻风格，不做写实刀具；战斗只有击退，不扣血、不出血。
  • 对外统一叫「梦魇影」「暗影」，不用恶灵、鬼魂这类词。
  • 简介里不用「第一」「最强」「官方」这类词。
