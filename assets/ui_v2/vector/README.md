# 代码地图草案

按用户 2026-11-11 的要求：不用生成地图图片，不逐棵读取或绘制场景树。此目录与主场景隔离，未执行导入、运行或保存。

- `tools/ui/build_vector_map.py`：从原生高度数据提取海岸与地形等高线，简化路径；输出代码几何与 SVG 检查稿。
- `map_geometry.lua`：运行时所需线条和地点数据，约 42 KB。树林为 12 个区域示意符号；无需扫描场景树。
- `map_renderer.lua`：待实测的 Unity Canvas 适配器。静态纸底、线条、标签遮罩合为一个 Mesh；文字和按钮保持真实 UI 控件。使用公共 API 声明中的 VertexHelper 和 CanvasRenderer；无地图图片加载。白色引擎默认纹理仅为 UI 材质所需，不是地图贴图。
- `map_preview.svg`：同一份几何数据的离线检查稿，不是运行时资源。已查看缩略图，地点文字无明显重叠。SVG 文字的系统字体与最终运行字体可能不同。

当前核验：229 条路径、1,644 条线段；静态绘图约 6,668 个顶点（包含纸底和 22 个标签遮罩），只在建立面板时构建。未测实际帧率或编辑器容量，不以数据大小代替性能验收。

接入时必须完成：

1. 以最新场景为基准，移除地图对 `ui_map` 贴图的等待与显示；保留故事书等其它贴图。
2. 用 mount 返回的根节点接入原地图显隐，卸载时调用 Destroy；不要每帧重建。
3. 统一使用 worldToCanvas 转换玩家箭头和地点，不能混用旧的 1520 像素布局标签偏移。
4. 地点按钮回调接旧地点卡片；新三处补齐卡片。幽灵挑战坐标 (157,27) 当前是候选，待战斗侧确认。
5. 世界时间由共享昼夜模块写入 SetClock；未同步时显示“同步中”，不伪造时间。地图按钮下移、任务进度提示仍待接入现有 HUD。
6. 最新模型和地形可能还未保存，发布前重新核对地点与高度数据。此版不覆盖用户正在修改的场景。

本轮只完成独立代码地图草案，未完成编辑器运行验收。
