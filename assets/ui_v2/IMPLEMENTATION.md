## v7 图片加载修复

v6 实测出现第一张职业插画白块，随后 WebAssembly memory access out of bounds / null function。v7 移除运行时 ImageConversion.LoadImage 和图片 Base64，改用独立 GLB 材质贴图，与原故事书的纹理读取方式保持一致。图片原始像素保留，贴图载体在地下并在读取后关闭 Renderer。该修改的因果关系须以运行复测确认。
