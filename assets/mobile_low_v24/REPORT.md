# 龙眠手机低负载版 v24

用户已确认 v23 的模型在手机可见；本轮保留该模型兼容包，不改战斗规则，不加入存档或无限资源，不推送 GitHub。

## 改动
- 三职业低特效分支：取消余爆堆叠、技能全屏闪光与震屏；短效果并发上限 4、飞弹上限 2、短效果约 0.55 秒回收。8 个粒子资源各只启用 2 层、合计上限 8 粒子。
- 关闭后处理、Bloom、暗角、实时阴影、HDR/MSAA；三维 renderScale 上限 0.6。30 FPS 目标在启动结束后仍按每秒检查，避免平台初始化覆盖。
- 古书与地图纹理解码不再生成 mipmap，释放 CPU 可读副本；保留 UI 分辨率。标题镜头避免同时开启两台世界相机。
- 房间/角色/书页/模型准备增加阶段提示与超时提示；模型就绪检查 1 Hz。平台在 Lua 启动之前的开发版黑屏尚未定位。
- 毒蘑菇不再修改相机 FOV，眩晕只作轻微摇晃。效果替换、结束时清理眩晕，修复浮点相等判断导致的 FOV 恢复失败。
- 删除旧的隐藏影灵模板 700916460（备份在 main-before.scene.data），当前战斗使用 ShadowSpiritSource。旧模板与新版控制器身份冲突导致保存失败。

## 已取得证据
- 全部 Lua 语法检查、模拟突发负载上限和回收测试通过。
- 主场景原生探针遍历三职业普攻及三个技能：取样最多 21 活动粒子，结束后系统与粒子均回到 0，相机始终 1 台。飞弹内部另有平台附加粒子系统，不能用资源上限 8 直接当全场上限。
- 主场景毒/熟/毒/熟连续交替：FOV min=max=45，熟蘑菇立刻取消眩晕，清理后 FOV=45。
- 降档读回：shadows=0，shadowDistance=0，renderScale=0.60000002，HDR/MSAA=false。初次发现 FPS 被平台重设为 60，随后补上持续低频守护；最终版 probe-final.json 已读回 targetFPS=30，其余参数仍正确。
- native 检查没有临时脚本 hook；这些测试不是 iPhone 真机验收。

## 加载与大小的限制
main-before.scene.data 为 5.079549 MB，仅本地场景序列化，不是包含外部依赖的完整手机包。手机显示的 30 多 MB 统计口径未确认，不能与他人 200 MB 直接比较，更不能用下载量推断实时渲染负载。缓存减少下载，仍需 GPU 渲染。

本地加载抽样显示编辑器 Renderer 物理内存约 2.5 GB、进程峰值 3.0 GB，包含编辑器，不代表手机内存。采样缺少 WASM 符号，未归因具体函数。iPhone 闪退原因和开发版黑屏仍需新包真机验证。
